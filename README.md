# 头部测量 · 行业对比

静态 Three.js 应用。29 类标准测量点展开为 45 个左右独立点，另有 4 个辅助操作点；29 个测量项目；9 个行业预设。

## 交互

- 测量点：点击头模上的点或勾选点名称，满足项目定义时自动显示测量线。候选项目列出尚缺的点，点击可补齐。勾选框控制路径显示，点击项目名称突出当前路径，再次点击恢复全部。
- 行业对比：可同时选择行业。蓝色表示所有已选行业共有项目，其他颜色表示独有或部分行业共有项目。可切换全部、共同、差异，并逐项隐藏路径。
- 单侧测量可切换左右耳。左右以受测者为准。
- 头戴设备方案保留原六项及“必测／建议测量”分类。行业表未提供测量级别，行业模式不推断必测级别。
- 全部名称显示当前视角可排布的点名，转动头模查看其余点。选中点及当前项目的点名优先。

## 依据与配准

测量点名称和29项编号对应用户提供的 GB/T 2428—2024 图 A.1、A.2；行业对应关系读取《各行业头部测量项目对照表.xlsx》的“行业测量项目”工作表。原始表格及标准截图不嵌入公开部署包。

头围沿用原项目指定的 WS/T 424—2013 操作定义。行业表只含项目名称，不包含各品牌量带定位差异。颈椎点与颌下定位处作为辅助点单独说明。

所有点位和贴表路径是提供的 STL 上的人工示意配准，未取得解剖学标定。瞳孔、发缘及需触诊的标志须在实际采集时确认。垂直、前后投影尺寸以当前模型姿态示意，实际测量需按眼耳平面定位。本页不推断 STL 物理单位，不输出受试者实测数值。

## 本地运行与部署

运行 `python3 -m http.server 4175 --directory dist`，在浏览器打开终端中的本地地址。

`dist/` 为完整静态网站，无构建步骤，Three.js r170 与 OrbitControls 随包提供。头模分为13个二进制块，加载后按原顺序拼接，保留原模型字节。

GitHub Pages 使用 `gh-pages` 分支根目录，包含 `.nojekyll`。

`scripts/prepare_extended.py` 从前一版本网格和用户 Excel 生成扩展点位、路径与行业映射，需要 numpy、openpyxl；脚本中的输入路径用于本机维护。`scripts/package_offline.py` 生成双击可打开的离线 HTML。
